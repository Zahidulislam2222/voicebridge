# Integration infrastructure

`n8n/confirmation.workflow.json` maintains the local confirmation workflow and
receipt/operation contract. Configure credentials/identity privately and inspect
existing imports before creation/publication. Never embed keys in workflow exports.

Actual calendar/CRM/email/provider execution needs reviewed configuration and
live acceptance. Publishing source does not enable integrations or create cloud
resources. See [operations](../docs/core-engine-operations.md) and
[API](../docs/api/README.md).
