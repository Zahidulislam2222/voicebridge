# Contributing

Describe the problem, behavior and acceptance criteria in a focused issue/PR.
Security reports follow [SECURITY.md](SECURITY.md). Preserve migration/data contracts.
Use typed settings for environment values and validated files for product content.
Never commit credentials, participant/client data or private evidence.

Run relevant tests, types, lint, scans/builds and exercise the changed real flow.
Document dependencies, limits and migration/rollback; update relevant READMEs and
evidence while retaining dated history. Keep ordinary tests provider-disabled.
Do not bypass hooks or push protection. Dependencies require registry/licence review.
Contributions are subject to [repository rights](LICENSE); contact the author
before assuming reuse or redistribution permission.
