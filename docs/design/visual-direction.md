# VoiceBridge visual direction

The public site uses warm ivory, lavender and mint, generous DM Sans/Manrope
headlines, thin dividers and a navy workflow sequence. The signature visual is a
responsive, iridescent Three.js voice sculpture with conversation/booking cards.
The approved operator dashboard retains its pearl surfaces, dark ink, restrained
accent, aligned tables and clear working controls.

Home is a full narrative: hero, business-use strip, product view, scroll-led
workflow, capabilities, industry selector, integrations, FAQ, closing action and
footer. Product, Solutions, Pricing, Company, Resources, Contact and Get Started
are distinct complete destinations. Motion confirms navigation and guides the
story; it has a pause control, static fallback and live reduced-motion handling.

The user explicitly requested removing presentation labels from visible copy.
Use VoiceBridge, Northline and product terms. Developer documentation preserves
the in-memory/provider boundary; visible copy never claims remote submission,
account creation, invented pricing, testimonials, compliance, capacity or uptime.

UI UX Pro Max's installed search guidance informed spacing, hierarchy and
accessibility. The warm violet direction and existing local typography are
intentional choices. The public MotionSites gallery informed the original visual
reference; membership-gated prompts were not copied.

## Research

- [Motion scroll](https://motion.dev/docs/react-use-scroll) and [accessibility](https://motion.dev/docs/react-accessibility)
- [Motion reduced motion](https://motion.dev/docs/react-use-reduced-motion); installed version behavior was also inspected
- [React browser subscriptions](https://react.dev/reference/react/useSyncExternalStore)
- [Three.js installation](https://threejs.org/manual/en/installation.html) and [renderer](https://threejs.org/docs/#WebGLRenderer)
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
- [MotionSites public gallery](https://motionsites.dev/en)

Original design brief: Build a calm, distinctive voice receptionist product with
an ivory/lavender editorial homepage and an iridescent 3D voice sculpture. Pair
large clear type with full product/industry/resource pages, meaningful scroll
storytelling, responsive layouts and accessible controls. Keep the existing light
operator dashboard. Review forms locally until authenticated backend integration.

## Asset provenance

Hero: repo-native Three.js geometry/material/lighting. Visual parameters live in
validated site data. Pause, viewport/visibility, reduced motion and initialization
fallback govern rendering; resources are released when the visual unmounts.

Supporting asset: apps/web/public/voice-sculpture.png, built-in image generation,
new opaque-background image inspected in the workspace. Tool did not expose model
version or charge. No new billed image/video API was used for this rebuild.

DM Sans and Manrope come from official Google Fonts distribution files and retain
their SIL Open Font Licenses under apps/web/public/fonts/. Local presentation
packaging embeds fonts/artwork with no external font URL.

Original image prompt: Cinematic optical-glass acoustic bridge formed by an
interlaced flowing loop, connecting two voices through fine platinum wave etchings.
Right-weighted landscape frame, midnight navy studio, polished silver, clear glass,
icy cyan/periwinkle caustics, realistic reflections and rim lighting. No text,
logos, people, controlled interface or watermark.
