# Security policy

The maintained default branch is the current security-support target. A long-term
support version schedule has not been published.

Use **Report a vulnerability** on the repository Security tab:
https://github.com/Zahidulislam2222/voicebridge/security/advisories/new
Sensitive reports belong in private reporting, not public issues.

Include revision, minimal reproduction, impact and expected/actual behavior.
Exclude credentials, personal information, recordings and database dumps. Coordinate
live testing; avoid denial of service and provider charges. The maintainer assesses
reports and coordinates fixes/disclosure; response times are not contractual.
See [security model](docs/security-model.md) and [runbooks](docs/operations-runbooks.md).
